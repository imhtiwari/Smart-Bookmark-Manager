# Smart-Bookmark-Manager
🔖 Smart Bookmark Manager

Smart Bookmark Manager is a modern, animated web application that allows users to save, search, edit, and manage website bookmarks in real time. It features smart URL normalization, duplicate protection, persistent LocalStorage saving, and a sleek glassmorphism UI.

🚀 Features

Real-time search filtering

Smart URL normalization & duplicate prevention

Persistent storage using LocalStorage

Edit & delete bookmarks dynamically

Delete all bookmarks instantly

Animated glassmorphism UI

Fully responsive design

🛠 Tech Stack

HTML5

CSS3 (Glassmorphism + Animations)

JavaScript (DOM, Events, LocalStorage)

📂 Project Structure
Smart-Bookmark-Manager/
│
├── index.html
├── style.css
└── index.js

⚙️ How to Run

Download or clone the repository

Open index.html in your browser

Start saving your bookmarks

No server setup required.
